# 📬 Email Marketing Campaign Optimization (ML Case Study)

## 🧠 Project Overview
This project focuses on optimizing an email marketing campaign using machine learning. Given user engagement data from a real e-commerce campaign, we aim to:

- Analyze email open and click-through rates (CTR)
- Predict which users are likely to click the email link
- Simulate smarter, model-based targeting strategies to improve CTR
- Extract performance insights across email versions, content types, and timing

---

## 📁 Dataset Details

The project uses 3 CSV files:
- `email_table.csv`: Metadata for each email sent
- `email_opened_table.csv`: IDs of emails that were opened
- `link_clicked_table.csv`: IDs of emails that had the link clicked

---

## 🚀 Key Features
- 📊 Open Rate & Click-Through Rate analysis  
- 🤖 XGBoost model to predict clicks  
- 🎯 Threshold tuning (precision, recall, F1 score)  
- 📈 Simulation of CTR uplift with top 30% targeting  
- 🔍 Segmentation analysis (email format, personalization, weekday)  
- 📉 Heatmap visualization of CTR performance by segment
